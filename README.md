# 봉일천고 골든벨 (주요과목 퀴즈 사이트)

**바로 가기: [https://2023swhs3rd-a11y.github.io/quiz/](https://2023swhs3rd-a11y.github.io/quiz/)**

일반계 고등학교 학생용 5지 선다 퀴즈 사이트입니다. 봉일천고 진로진학부 사이트의 공통 디자인을 따르며, 서버 없이 정적 파일만으로 동작합니다. 현재 1,800문항입니다. 과목 6 × 학년 3 × 난이도(하·중·상) 54칸마다 30문항에, 수능 실전 수준의 **최상** 난이도를 고3에 과목마다 30문항 더했습니다.

## 구성

| 파일 | 용도 |
|---|---|
| `index.html`, `manifest.webmanifest`, `sw.js`, `icon-*.png` | **배포되는 웹앱.** GitHub Pages가 그대로 내보내 `https://2023swhs3rd-a11y.github.io/quiz/` 에서 열립니다. 손으로 고치지 않고 빌드로 만듭니다. |
| `src/data/q_*.py` | 과목별 문항 원본. 문항을 고치거나 추가할 때 이 파일을 수정합니다. |
| `src/app.html` | 화면(디자인·동작) 원본 |
| `src/data/figs.py` | 문항에 넣는 그림·도표(SVG) 도우미: `table`(표), `bars`(막대그래프), `Plot`(좌표평면·함수 그래프), `shape`(도형). 글자색을 따라가므로 다크 모드에서도 보입니다. |
| `src/build.py` | 문항 형식 검사 + 지문 중복 검사 + 칸별 문항 수 확인 + 정답 번호 분포 조정 + 결과물 생성 |
| `scripts/feedback-apps-script.gs` | '이 문제 이상해요' 제보를 구글 시트에 모으는 Apps Script |
| `questions.json` | 문제은행 전체(검토·백업용) |
| `dist/standalone.html` | 인터넷 없이 파일 하나로 여는 단독 실행용 |

## 진로진학부 사이트에 올리기

1. 저장소 Settings › Pages 에서 Branch를 `main`, 폴더를 `/ (root)`로 지정합니다. 다른 브랜치로 잡혀 있으면 `main`에 병합해도 사이트가 바뀌지 않습니다.
2. 첫 화면(픽셀 학교)에 교실을 더하려면 `2023swhs3rd-a11y.github.io` 저장소 `index.html` 의 교실 바로가기 목록(`a.card`)에 `/quiz/` 를 추가합니다.

- 화면은 사이트 공통 스타일 `/assets/site.css` (Pretendard 글꼴, `--bon-*` 색, 맨 위 경로 줄, 바닥글)를 그대로 불러옵니다. 이 사이트 고유색은 `#a16207` 입니다.
- 웹앱: 휴대폰 브라우저의 '홈 화면에 추가'로 설치할 수 있고, 한 번 연 뒤에는 인터넷이 끊겨도 열립니다(`sw.js`).
- 저장소 이름을 바꾸면 `src/build.py` 의 `SITE_PATH` 를 고치고 다시 빌드합니다.

## '이 문제 이상해요' 제보 받기

문제 화면 오른쪽 위의 작은 **이 문제 이상해요**(접혀 있음)를 누르면 사유(정답이 틀린 것 같아요 / 해설이 이상해요 / 오타 / 기타)와 내용을 적어 보낼 수 있습니다. 보낸 제보는 문항 번호·과목·학년·난이도와 함께 구글 시트에 한 줄씩 쌓입니다.

1. 제보를 모을 새 구글 시트를 열고 확장 프로그램 › Apps Script 에 `scripts/feedback-apps-script.gs` 내용을 붙여 넣고 저장합니다.
2. 배포 › 새 배포 › 유형 **웹 앱**, 실행 사용자 **나**, 액세스 권한 **모든 사용자**로 배포하고 권한을 허용합니다.
3. 나온 웹 앱 주소(`https://script.google.com/macros/s/…/exec`)를 `src/build.py` 의 `FEEDBACK_ENDPOINT` 에 넣고 다시 빌드해 커밋합니다.

주소가 비어 있으면 "준비하고 있어요"가 뜨고 '내용 복사'만 됩니다. 시트의 '문항 번호'(예: `MA-012`)로 `questions.json` 이나 `src/data/` 에서 해당 문항을 찾을 수 있습니다.

## 기능

- **연습 모드**: 과목(국어·영어·수학·한국사·통합사회·통합과학), 난이도(하·중·상·최상), 학년(고1~3), 유형(**단편지식형** / **수능형**)을 골라 **한 문제씩**(원하는 만큼) 또는 **10문제씩** 풀기
- **골든벨 모드**: 6과목에서 고르게 섞인 50문제를 무작위로 출제(학년 선택 가능), 최고 기록(맞힌 수·시간) 저장
- 화면 위쪽에 문제별 소요 시간과 총 소요 시간, 언제든 누를 수 있는 **처음으로** 버튼 표시. 결과 화면에 총 시간·문제당 평균
- 문항마다 채점 → 정답 표시 + 해설, 필요한 문항에는 그림·표·그래프
- 결과 화면: 점수, 과목별 정답률, 틀린 문제 해설 모아 보기, 틀린 문제 다시 풀기
- 오답 노트: 틀린 문제를 브라우저에 저장해 두고 나중에 다시 풀기 (맞히면 자동으로 빠짐)
- 키보드: 숫자 1~5로 선택, Enter로 채점/다음
- '이 문제 이상해요' 제보 버튼
- 휴대폰 화면, 다크 모드 지원

## 문항 추가·수정 방법

1. `src/data/q_과목.py`에 아래 형식으로 한 줄을 추가합니다.

```python
Q("단편", 1, "중", "발문",
  ["선택지1", "선택지2", "선택지3", "선택지4", "선택지5"], 3,   # 정답 번호(1~5)
  "해설", 지문)   # 지문은 수능형에서만, 없으면 생략
```

- 유형: `"단편"`(단편지식형) 또는 `"수능"`(수능형)
- 학년: 1, 2, 3 / 난이도: `"하"`, `"중"`, `"상"`, `"최상"`(수능 실전 수준, 지금은 고3에만 있음)
- 굵게 `<b>`, 밑줄 `<u>`, &lt;보기&gt; 상자 `<div class='box'>…</div>` 를 쓸 수 있습니다.
- 그림·표는 `from figs import table, bars, Plot, shape` 로 만들어 지문 자리에 넣습니다(지문 문자열과 `+`로 이어 붙여도 됩니다).
- **한 지문에는 한 문항만** 만듭니다. 같은 지문(공백 무시)이 두 번 나오면 빌드가 멈춥니다.
- &lt;보기&gt; 상자 안에서 줄을 바꾸려면 `<br>`을 씁니다.

2. 터미널에서 `python3 src/build.py` 를 실행하면 형식 오류를 검사한 뒤 배포 파일과 `questions.json`이 새로 만들어집니다. 과목·학년·난이도 칸마다 문항 수를 보여 주고, 20개에 못 미치는 칸이 있으면 알려 줍니다. 새 문항은 해당 과목의 마지막 파일(예: `q_math5.py`) 끝에 추가하거나, 새 파일을 만들어 `build.py` 의 `MODULES` 에서 그 과목의 마지막 파일 뒤에 넣어야 기존 문항 번호가 바뀌지 않습니다.

> 정답 번호가 과목마다 한쪽에 몰리지 않도록 빌드할 때 선택지 위치를 자동으로 조정합니다(최상 문항은 따로 맞춥니다). ①~⑤를 지시하는 문항, ㄱ·ㄴ·ㄷ 조합, 순서 배열, 해설에서 번호를 언급하는 문항은 순서를 그대로 둡니다.

## 주의

- 모든 문항은 학습용으로 새로 작성한 창작 문항입니다(실제 수능·EBS 문항을 옮기지 않음).
- 오답 노트는 학생 각자의 브라우저에만 저장되며, 교사에게 전송되지 않습니다. 제보에는 이름을 받지 않습니다.
